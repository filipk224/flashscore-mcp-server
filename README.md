# Flashscore MCP Server

## Features
Access any sporting league that is available on flashscore.com. Extract team names, scores, dates, games played, wins, losses, points, form, fixtures, previous seasons, news headings with links etc.

League tools accept the name with its country (Premier League (England) or NBA (USA)) as well as a Flashscore path.
